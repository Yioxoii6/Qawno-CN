# Qawno-CN 汉化说明

本项目是 [open.mp/qawno](https://github.com/openmultiplayer/qawno) 的中文本地化版本，
基线为上游提交 `5ad664c`（v1.2.0.2670）。

## 三条主线改动

### 1. MSVC 下的源码编码（`CMakeLists.txt`）

```cmake
if(MSVC)
  add_compile_options(/utf-8)
endif()
```

不加这一条，MSVC 会把源码与 `.ui` 里的 UTF-8 中文按 GBK 解释，界面文字全部乱码。

### 2. GBK / GB2312 脚本支持

Pawn 脚本在中文 Windows 上普遍是 GB2312/GBK 编码，而 qawno 默认按 UTF-8 读写。
本项目让编辑器按 GBK 读写脚本，避免打开中文脚本时中文变乱码、保存时又写坏原文件。

### 3. 界面汉化

分三块，因为**来源不同、解决办法也不同**：

| 范围 | 来源 | 做法 |
|---|---|---|
| 主窗口菜单栏、6 个对话框（查找/替换/服务器设置/编译器设置/跳转/关于） | qawno 自己的 `.ui` 文件 | 直接改 `.ui` 里的字符串 |
| 消息框按钮（OK → 确定）、文件对话框（Open → 打开） | Qt 内置 | `main.cpp` 装入官方 `qt_zh_CN.qm` |
| **右键菜单（撤销/重做/剪切/复制/粘贴/删除/全选）** | Qt 内置 | **必须自己改代码，见下** |

#### 右键菜单为什么要自己改代码

两条实测结论（`qt_zh_CN.qm` 转成 `.ts` 后用 `lconvert` 逐条统计得到）：

1. **Qt 5.15.2 官方 `qt_zh_CN.qm` 里根本没有标准右键菜单的词条。**
   该文件共 1395 条翻译，`&Undo` / `&Redo` / `Cu&t` / `&Copy` / `&Paste` / `&Delete`
   **一条都没有**；只有 `Select All` 存在，且属于 Qt3 遗留上下文 `Q3TextEdit`，
   Qt5 的 `QPlainTextEdit` 根本不会去查它。**所以装 `qt_zh_CN.qm` 治不了右键菜单。**

2. **`createStandardContextMenu()` 在 `QPlainTextEdit` 里不是虚函数**
   （`qplaintextedit.h:164` 没有 `virtual`），**无法重写**；
   只有 `contextMenuEvent()`（`:252`）是虚函数。所以在子类里重写它、取出基类菜单再改文字。

实现见 `src/ContextMenuChinese.h` 与 `EditorWidget` / `OutputWidget` 的 `contextMenuEvent`：

```cpp
void EditorWidget::contextMenuEvent(QContextMenuEvent *event) {
  QMenu *menu = createStandardContextMenu();   // 取基类的标准菜单
  qawnoTranslateContextMenu(menu);             // 逐项换成中文
  menu->exec(event->globalPos());
  delete menu;
}
```

**踩坑（值得记下）**：Qt 把快捷键**拼在 `QAction::text()` 里、用 `\t` 分隔**
（实测就是 `"&Undo\tCtrl+Z"`），而且"删除"那一项的文字是 `Delete`（**没有 `&` 前缀**）。
所以匹配前必须按 `\t` 拆开、只查标签部分，拼回去时快捷键原样保留 ——
否则一条都匹配不上（这个 bug 就是被下面那个测试当场抓出来的）。

## 构建

环境：Qt 5.15.2 (msvc2019_64) + Visual Studio（CMake 生成器 `Visual Studio`）。

```
cmake -S . -B build -DCMAKE_PREFIX_PATH="D:/Qt/5.15.2/msvc2019_64"
cmake --build build --config Release
```

产物：`build\Release\qawno.exe`

## 部署（重要）

```
qawno.exe
qt_zh_CN.qm      ← 必须与 qawno.exe 同目录，否则消息框按钮会变回英文
Qt5Core.dll  Qt5Gui.dll  Qt5Svg.dll  Qt5Widgets.dll
libEGL.dll   libGLESv2.dll
platforms\  styles\  imageformats\  iconengines\      ← 缺 platforms\ 会报"找不到平台插件"
```

## 如何验证右键菜单真的汉化了

GUI 截图不便复核，这里给一个**无界面、可复现**的验证方式：建一个 `QPlainTextEdit`，
取它的标准右键菜单，套用汉化函数，把菜单项打印出来（`-platform offscreen` 无需显示器）。

实测输出：

```
汉化前                     汉化后
&Undo       Ctrl+Z   →   撤销(&U)   Ctrl+Z
&Redo       Ctrl+Y   →   重做(&R)   Ctrl+Y
Cu&t        Ctrl+X   →   剪切(&T)   Ctrl+X
&Copy       Ctrl+C   →   复制(&C)   Ctrl+C
&Paste      Ctrl+V   →   粘贴(&P)   Ctrl+V
Delete               →   删除(&D)
Select All  Ctrl+A   →   全选(&A)   Ctrl+A
```
